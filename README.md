# 3D Architectural Door Assets

Welcome to this repository containing high-quality, rendered 3D door models. This collection features two distinct architectural styles designed for interior environments, ranging from clean modern layouts to culturally inspired heritage spaces. 

## Models Included

### 1. Modern 3-Panel Interior Door
A clean, minimalist interior door featuring a smooth matte finish and a classic three-panel design. Ideal for modern architectural visualizations and standard residential layouts.

![Modern Door Front](Door-1.jpg)
![Modern Door Angle](Door-1-2.jpg)

### 2. Traditional Indian Carved Wood Door
A high-gloss varnished wood door detailed with traditional floral relief carvings. This model integrates cultural architectural elements and intricate texturing to create a rich, heritage aesthetic.

![Traditional Door Front](Door-2.jpg)
![Traditional Door Angle](Door-2-2.jpg)

## Technical Overview
* **Modeling & Texturing:** Crafted and rendered in Blender.
* **Materials:** Features custom wood textures with distinct surface finishes (matte and high-gloss varnish).
* **Application:** These assets are structurally optimized to be dropped into 3D architectural scenes or integrated into interactive web-based 3D environments.
